# Portfolio — Sai Kumar Chinthakayala

Interactive personal portfolio for **Sai Kumar Chinthakayala**, Full-Stack Developer / Agentic AI Engineer.

Built with **React 18 + Vite 6 + Tailwind CSS 3**.

## Features

- Sticky navbar with light/dark theme toggle (follows system preference)
- Hero with circuit-trace portrait, traveling glow pulses, and role nodes (AI Agents, APIs, CI/CD, MCP, LLM)
- Editorial About section, animated Experience timeline with git graph
- AI Skills showcase, 13 certifications in a 3D Cover Flow
- Selected Work with real project screenshots
- Premium contact form (EmailJS) and an "Ask about Sai" chatbot
- Roaming AI logos, scroll progress, reduced-motion support, fully responsive

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
